# Social Links Profile

Perfil de links responsivo desenvolvido como solução para um desafio do [Frontend Mentor](https://www.frontendmentor.io/).

[![Abrir projeto](https://img.shields.io/badge/Abrir_projeto-C4F82A?style=for-the-badge&logo=googlechrome&logoColor=141414)](https://marcosloll.github.io/Social-links-profile/)
[![Código](https://img.shields.io/badge/Ver_código-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/marcosloll/Social-links-profile)

## Sobre o projeto

O desafio consiste em reproduzir um cartão de perfil com foto, localização, apresentação e links sociais, mantendo o layout próximo da referência em diferentes tamanhos de tela.

## Funcionalidades

- Cartão de perfil responsivo.
- Links sociais organizados em botões.
- Estados visuais de interação para mouse e teclado.
- Estrutura semântica e imagem com texto alternativo.

## Aprendizados

Este projeto ajudou a praticar organização semântica do HTML, Flexbox, unidades relativas, responsividade e estados de foco e hover.

## Executar localmente

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` diretamente no navegador ou com o Live Server.
